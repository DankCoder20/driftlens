# REST API

Send `Authorization: Bearer <DRIFTLENS_API_TOKEN>`. `/api/health` is unauthenticated. JSON errors use `{"error":{"message":"..."}}`. Cross-origin browser API requests are rejected.

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Liveness |
| GET | `/api/state` | Latest snapshot and running state |
| GET / POST | `/api/repositories` | List/add repositories |
| DELETE | `/api/repositories/{id}` | Remove unreferenced repository |
| POST | `/api/repositories/{id}/test` | Checkout and discover files/charts |
| GET / POST | `/api/clusters` | List/add kubeconfig references |
| DELETE | `/api/clusters/{id}` | Remove unreferenced cluster |
| POST | `/api/clusters/{id}/test` | Test authentication and server version |
| GET / POST | `/api/mappings` | List/add explicit environments |
| DELETE | `/api/mappings/{id}` | Remove mapping |
| GET / PUT | `/api/settings` | `{"scanInterval":300}`; 0 disables polling |
| POST | `/api/scans` | Start async scan; 202 or 409 if busy |
| GET | `/api/scans` | Recent scan summaries |
| GET | `/api/inventory` | Filter with `cluster`, `namespace`, `kind` |
| GET | `/api/inventory/{id}?cluster=...` | URL-encoded identity, cluster required |
| GET | `/api/drift` | Filter with `repository`, `environment`, `cluster`, `namespace`, `kind`, `classification` |
| GET | `/api/drift/{id}` | URL-encoded comparison ID |
| GET | `/api/topology/{clusterId}` | Resource nodes and verified edges |
| GET | `/api/analytics/overview` | Latest aggregate summary |
| GET | `/api/analytics/drift` | Historical scan summaries |
| GET | `/api/analytics/resources` | Historical scan summaries |
| GET | `/api/history` | Commit, drift and health changes |
| GET | `/api/events` | Authenticated SSE; connected, scan-started, scan-complete, scan-failed |

POST repository body: `{"name":"infra","url":"https://github.com/team/infra.git","branch":"main"}`.

POST cluster body: `{"name":"dev","kubeconfig":"dev.kubeconfig","context":"dev-readonly"}`. This endpoint never accepts kubeconfig contents.

POST mapping body:

```json
{
  "name": "development",
  "repositoryId": "<repository ID>",
  "clusterId": "<cluster ID>",
  "chartPath": "charts/platform",
  "release": "platform",
  "namespace": "development",
  "valuesFiles": ["charts/platform/values-dev.yaml"],
  "kubeVersion": "1.34.0",
  "apiVersions": [],
  "ignorePaths": []
}
```

Set `manifestPath` to add a raw YAML directory, or use it without `chartPath`. IDs are generated by the server. Bodies are limited to 1 MiB. Removing a connection referenced by a mapping returns 409. A successful connection test verifies connectivity; the next full scan reports granular RBAC/list failures.
